Padlet Breakout Linker

No configuration is required. The extension works automatically:

  • It reads each section’s breakout room link directly from Padlet’s own board data (breakoutLink on each section), so every open-in-new button is wired with no copy‑and‑paste.
  • A small open-in-new icon (square with an arrow to the upper right) is placed to the left of each section’s “⋯” menu (detected precisely by its aria-label). It never appears on posts, the top toolbar, or the settings panel. The button is transparent when not yet linked, turns green once its link is found, and flashes yellow if it cannot find the link.
  • Click an open-in-new button to open that section’s breakout room in a new tab only — the current tab never navigates.
  • As a safety net, if you ever use Padlet’s own “⋯ → Copy breakout room link”, the link is captured silently and attributed to the section you clicked. Alt+click an open-in-new button to clear its saved link.

Saved links are stored per board + section in the browser’s local storage and persist across reloads.
