Padlet Breakout Linker

No configuration is required. The extension works automatically:

  • It reads each section’s breakout room link directly from Padlet’s own board data (breakoutLink on each section), so every 🔗 button is wired with no copy‑and‑paste.
  • A small 🔗 icon is placed to the left of each section’s “⋯” menu (detected precisely by its aria-label). It never appears on posts, the top toolbar, or the settings panel.
  • Click a 🔗 button to open that section’s breakout room in a new tab only — the current tab never navigates.
  • As a safety net, if you ever use Padlet’s own “⋯ → Copy breakout room link”, the link is captured silently and attributed to the section you clicked. Alt+click a 🔗 button to clear its saved link.

Saved links are stored per board + section in the browser’s local storage and persist across reloads.
